# 04：查看计划详情和版本，并保留所选数据到 Session

## What to build

用户从已有计划列表打开详情，查看版本列表并明确所选版本，然后把已取得的详情和版本信息作为快照送入 Session。仅凭第 01 张任务提供的单页列表即可演示本流程，不依赖筛选和分页功能完成。

## Acceptance criteria

- [ ] 根据已确认的 GEA 只读接口取得计划详情和版本列表，页面清楚显示计划身份及所选版本，不新增或调用保存、审批和写回接口。
- [ ] 区分计划级详情与版本级数据；若接口只提供当前计划详情，不把它冒充为某个历史版本的详情。
- [ ] 查看其他计划或版本时，显示内容和选择一致；延迟响应不会把上一条计划或另一版本的数据填入当前界面。
- [ ] 页面正确呈现无版本、无权限、缺失字段和部分返回，不以默认零值、当前版本或另一条记录静默替代缺失信息。
- [ ] 发送前可识别计划、版本和已取得范围；Session 快照保留来源、查询时间、计划/版本关系及明确的缺失项，后续服务端数据变化不改写既有快照。
- [ ] 自动回归从第 01 张任务的单页入口打开详情、切换版本并发送，独立核对实际 GEA 请求、模型输入和持久化结果，覆盖跨计划/版本乱序与部分返回。
- [ ] 新增脱敏的详情、版本页面预期及 Session 回放；数值和标识沿用准确解析，不在显示阶段重新转换丢失精度。

## Blocked by

- 01：独立安装后跑通登录、单页查询与 Session 读回。
