# 05：查看版本 SKU，并预览可发送的数据范围

## What to build

用户查看所选版本的 SKU 明细，在发送前看到实际取得了哪些记录、缺少哪些信息，并把这一范围与计划和版本一起保存到 Session。当前票仍可使用本地回执完成端到端演示，不以真实模型接入为前置条件。

## Acceptance criteria

- [ ] 使用已确认的指定版本 SKU 只读接口，展示对应版本和接口实际提供的 SKU 字段；不发明修正字段或未经确认的业务映射。
- [ ] 空结果、部分结果、服务拒绝和缺失字段分别呈现；如果接口有分页或范围限制，页面和快照保留实际覆盖范围。
- [ ] 快速切换版本时，SKU 请求、页面明细和待发送快照始终归属于当前选择；旧请求失败或完成均不能污染新选择。
- [ ] 发送前展示计划、版本、数据条数、获取时间和缺失项；快照不会混入另一版本 SKU 或未明确选中的计划。
- [ ] 对单次快照提供可配置的大小限制；超限时提示收窄范围并显示实际选择，不能静默截断后声称完整。模型专属输入预算在真实分析整合票中处理。
- [ ] 本地回执路径实际收到包含 SKU 的相同快照；磁盘独立读回保留 SKU 标识、精确数量/金额、范围和来源。
- [ ] 无密钥产品回归及 Session/Web 预期覆盖空 SKU、部分返回、精确数值、乱序、错误和超限，所有样本脱敏。

## Blocked by
