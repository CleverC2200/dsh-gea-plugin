# 01：独立安装后跑通登录、单页查询与 Session 读回

## What to build

部署者在一个新目录安装外部 GEA 插件，通过官方 dsh CLI/profile 启动，用户从侧边栏扫码登录、读取一页计划、选择一条记录并在 Session 中看到本地验证回执，刷新后能读回相同数据。以现有已验证原型为起点，先完成后续功能需要的最小整理，不重建聊天、身份协议或 agent loop。

这张任务交付可复现的完整流程；本地回执明确标注为传递验证，不是真实 AI 分析。所有业务实现留在独立插件工程，dsh 源码和已安装依赖保持不变。

## Acceptance criteria

- [ ] 固定并记录已验证的 dsh 发布版本与插件版本；新目录中无需编辑源码或绝对插件路径即可安装、配置并通过官方 profile 启动。
- [ ] GEA 环境、超时、分页限制以及独立 Harness home 和工作区可配置；缺失或无效配置明确失败，不静默切换环境。
- [ ] 现有登录、单页真实查询、选中记录、Session 提交、本地回执和磁盘读回继续可用；页面显示环境、登录状态和本地回执的实际用途。
- [ ] Host 根据当次查询识别选中记录，快照保留环境、查询时间、计划/版本标识、当前页覆盖范围和精确数据；不能只用一个跨查询复用的行号选择记录。
- [ ] 页面、固定认证 Fetch 与标准 Session 接口承担完整流程；必要整理只分清 Client、Host 和快照职责，不新建 dsh Service Definition、Session 格式或额外聊天存储。
- [ ] 保留业务 GET 白名单和浏览器认证，未认证 Host 请求、外站 Origin、未登录业务查询及无效选择均被拒绝；凭证不进入页面、模型快照或诊断输出。
- [ ] 新增可从干净环境运行的产品级回归：启动真实 dsh profile，仅替换外部 GEA 和 LLM 响应，独立核对页面、实际模型输入和持久化读回；测试使用自己拥有的端口、进程及临时目录。
- [ ] 使用脱敏样本保存无密钥 Session 回放及 Web 预期；确认固定发布版提供的 snapshot/replay 接口可用，证据留在外部插件工程。

## Blocked by
