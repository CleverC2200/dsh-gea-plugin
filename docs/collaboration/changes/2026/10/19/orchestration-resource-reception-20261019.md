# 智能编排接收声明校验

智能编排主提示词补齐并进入统一 Agent 配置后，三包接收继续核完整标准能力及实际包内声明。原逻辑仅在 Manage company.20 添加主提示词和文件系统 Skill 目录，后续版本会因该旧版本判断被误拒绝。

本次去掉版本分支。读取实际包内主提示词；有受管智能编排资源时，核新 Home 未定制且正文与包内文件一致，按继承标准能力的声明比较。未采用受管资源的已支持包仍按其文件系统 Skill 声明比较，未携带主提示词的早期包保留原最小声明。该差异仅用于离线接收核验，不新增生产宿主回退或业务授权。

回归覆盖两种包内声明、早期最小声明、缺失或空正文拒绝及输入不变性。本次不修改插件运行时、版本或发行频道；与 Manage 的主提示词及配置入口候选配套。
