# 三插件新版准备

用户要求“用最新的代码发一版新的插件”。本轮从刷新后的 GitHub main 准备 Workbench 0.1.13、Manage 0.6.3-company.22、GEA 0.0.167；包含本轮之前已合并的共用 Workbench Agent、GEA SQL 接入及智能编排资源更新。

本轮仅增加版本和 GEA 对新组合的兼容声明，没有删除功能、文件或回退历史修复。版本常量检查和发行合同 12 项通过，另外两个 owner 的版本检查各 2 项通过。既有业务验收边界仍由原票维护。

此提交只表示发布准备。三个版本 PR 合并和必要检查通过后，才从固定主线构建，生成三包并验包，再发布到现有 OSS plugin-release/packages 和 plugin-detail-test、plugin-detail-stable。源码提交、构建回执、摘要及最终频道结果由本轮独立回执记录。未执行当前正式客户端安装、桌面打包或业务写入。

已读取主线新增更新记录与原更新故障记录，本轮未发现需要新建的业务 Bug。保留原失败及未完成验收。
