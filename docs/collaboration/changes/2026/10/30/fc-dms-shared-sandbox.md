# 分仓 DMS 共享测试接线

## 问题与行为

分仓确认弹窗在调用 DMS 前提示“DMS 当前环境或用户映射未配置”。原实现仅读取每台机器的显式部署配置；此前隔离测试进程的配置没有随插件交付，因此安装正式插件仍会触发拦截。

按本轮明确要求，未配置当前环境 DMS 部署时，插件内置固定测试网关、共享测试账号与测试签名凭据。正式 GEA 登录和取数环境保持原值，分仓主数据提示标注 DMS 测试环境。真实 GEA 租户及用户仍作为意图和回执归属，不改 Agent Skill、提示词或数据表。

显式部署保持优先，不匹配的显式账号、拒权、缺失密钥不会回退；内置凭据仅可用于固定测试网关。用户已明确接受内置测试签名凭据可从安装包提取，此例外仅覆盖测试 DMS，不包含正式 DMS 或其他系统凭据。

## 验证

- 原 Business 入口定向回归复现同样的映射错误，默认接线后通过；覆盖两个不同 GEA 用户、正式 GEA 环境不变、自定义部署拒绝回退及固定网关限制。
- 订单幂等、未知结果、重复批次、配置检查及主数据关联旧回归保留。
- 使用当前正式 GEA 身份及新默认配置，真实 DMS 测试登录返回成功，未新建订单；不将登录成功表述为完整暂存验收。

## 未完成的独立条件

分仓确认入库、分仓授权、快照重读和回执归档检查继续保留。当前正式 GEA 通用 SQL 接口的只读探针返回业务 400“执行失败”，本机没有分仓确认入库部署配置。因此完整客户端暂存仍需该通道就绪；本变更没有跳过持久化保护或凭空声明远端权限。

本轮未做三插件联合启动检查。PR、CI、发布和本地安装的实际状态由后续交付记录补充。
