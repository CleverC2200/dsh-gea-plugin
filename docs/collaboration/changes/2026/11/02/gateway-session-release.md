# 发布隔夜网关会话自动恢复修复

本轮以已合入 main 的 [PR #272](https://github.com/CleverC2200/dsh-gea-plugin/pull/272) 为业务改动，准备 GEA `0.0.212` 及 macOS arm64、Windows x64 客户端 `0.2.0-rc.2.20261102.2`。

隔夜继续时，明确的网关会话过期错误会触发同一调用内的一次重新握手和授权校验，再以原参数继续读取。撤权、拒权、取消、归属变化和再次过期保留失败。问题与历史证据沿 [原 Bug 记录](../../../../bugs/2026/09/BUG-20260925-gea-session-expiry.md) 维护。

对比插件 `0.0.211`，本轮只新增已合并的会话恢复修复及版本标识。Workbench `0.1.47`、Manage `0.6.3-company.44` 复用已发布归档；Manage 的 Windows Skill 快照竞争修复随本轮客户端一并内置。Core 保持 `a0c0d2ff884b1808eccb9bb254a1659281364d7d`、运行时版本 `0.2.0-rc.2`，不升级 Core。

源码修复的固定输入 CI 已通过，版本与产物仍须通过本轮发布预检、生产来源读回及双端打包验证。该准备记录不声明已上传、已安装或已完成真实设备升级。最终版本、固定下载、摘要、签名和验收边界由本轮 GitHub Release 记录。

未删除业务能力、测试、用户会话或草稿。此前“过期后下一轮再恢复”的交互按本轮明确要求调整，权限与执行归属保护保留。桌面自动更新频道不属于本轮下载包发布范围。
