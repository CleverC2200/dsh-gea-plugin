# 预警负责人白名单存储发行

计划发布 GEA 0.0.307，兼容 Workbench 0.1.128 和已发布 Manage company.81。负责人配置通过 PG-Warning 通用白名单接口保存，绑定当前环境、租户和账号，版本冲突拒绝覆盖。配置保留停用及退场标记，旧客户端不会将其当作可运行任务，普通任务仍能保存。无新增表、字段、权限或数据库直连。

功能 #439、旧版兼容 #440 已合入主线。6项存储回归、官方Core类型检查、旧版Host真实代码的读取/保存合同及插件构建通过；功能PR门禁通过。保留未知回执、身份切换、受控执行、DMS和现有更新器，未发现删除或历史修复回退，无新增Bug。

本次仅升版并增加配套 Workbench 精确兼容版本，发行后补记实际频道、下载及安装验收。测试使用模拟收件人，未调用真实消息发送。发布技能1.3.0为已确认的本机local_draft，不扩展Core或数据结构改动。
