# 库存加载与DMS配套发布

GEA 0.0.217配套Workbench 0.1.52与Manage 0.6.3-company.48。保留当前主线订单指标技能和员工身份修复；本轮调整分仓DMS目标解析，使用已发布仓库、经销商与提货点资源，完整字段对验证互换编码，仅唯一且全部匹配时填入。无正补货SKU不查询DMS主数据。

原历史资源查询由当前资源查询替代；显式地址必须在所选仓库范围内。错误、取消、多值、缺失与权限拒绝继续保持未知，不自动重试绕过网关。没有新增表或权限。旧FC_DMS_TARGET_SQL为未对外导出的内部实现，调用和回归已迁移，业务能力保留。29项GEA/DMS回归、4项实际SQL用例以及真实GEA主数据、生产DMS登录验证通过；未提交订单。用户随后明确“先写代码里吧”，本版临时内置固定正式DMS网关的Host签名配置，支持环境变量覆盖。已说明包内共享密钥可提取；测试环境和其他网关不允许使用该默认凭据，当前GEA身份核验保留。清除本机环境配置后真实正式登录通过。

发布技能1.2.0为本机local_draft，未登记团队维护仓。本轮获用户验证后发布授权；最终构建、频道和GitHub Release证据由发行回执记录。
