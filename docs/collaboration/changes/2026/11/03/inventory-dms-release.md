# 库存加载与DMS配套发布

GEA 0.0.217配套Workbench 0.1.52与Manage 0.6.3-company.47。保留当前主线订单指标技能和员工身份修复；本轮调整分仓DMS目标解析，使用已发布仓库、经销商与提货点资源，完整字段对验证互换编码，仅唯一且全部匹配时填入。无正补货SKU不查询DMS主数据。
