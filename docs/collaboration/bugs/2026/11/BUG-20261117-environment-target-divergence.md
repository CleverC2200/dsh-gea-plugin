# 登录环境与能力请求目标分别配置

能力自行选择请求目标，历史 DMS 默认允许正式 GEA 身份连接测试部署，日志的登录环境标签不足以证明实际请求来源。预警地址的端口本身不能证明测试环境，本轮未将截图推定为全部销售接口已经串库。

GEA 统一请求出口，在发出请求前校验能力部署与当前身份环境，切换身份后拒收旧响应。业务和 DMS 跟随登录环境；预警使用分环境显式配置；共享记忆保留环境、租户和用户归属。日志增加实际请求来源且保留元数据保护。

2026-11-17 已合并并发布 GEA 0.0.304，配套 Workbench 0.1.125 与 Manage 0.6.3-company.80。完整 CI、GitHub Windows、Mac 隔离原生安装及实际更新源下载通过，见[发布记录](../../../changes/2026/11/17/environment-isolation.md)。个人 Windows、真实生产业务、服务器代理和预警/记忆服务部署尚未验收，保留待验收状态。
