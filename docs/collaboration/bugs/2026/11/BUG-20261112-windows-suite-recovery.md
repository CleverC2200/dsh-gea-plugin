# Windows 覆盖安装后仍加载旧插件

用户报告在 Windows 覆盖安装新版客户端后，重启仍加载旧插件，删除 .dsh 才生效。原设备当前离线，尚未取得其故障回执，不能断言具体根因。

本轮源码检查确认，客户端覆盖安装的恢复需要完整内置三包身份和等待重启回执。GEA [PR #373](https://github.com/CleverC2200/dsh-gea-plugin/pull/373) 按完整三包恢复，并保留用户配置、失败证据与历史数据。既有 Mac 离线恢复、Windows Job 管理和来源校验继续保留；不要求清空 .dsh。源码检查与隔离官方接收已通过，Windows 签名安装和历史客户端恢复验收正在执行。

计划交付客户端 0.2.0-rc.2.20261112.2、GEA 0.0.269。员工原设备覆盖升级、实际账号和历史会话仍待验收；通过托管 runner 不等于通过该设备。
