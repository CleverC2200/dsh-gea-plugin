# 恢复旧插件后重复升级被备份冲突阻断

Mac 客户端 0.2.0-rc.2.20261112.2 在启动前报 `GEA_REFRESH_BACKUP_CHANGED`。现场验证脚本恢复了旧插件、安装声明与配置，却保留升级完成回执；再次启动时按相同起止版本复用原备份目录，恢复后的配置与旧备份不同，安装在写入前被拒绝。正常覆盖安装自身降级的假设未复现。

每次实际升级改为在安装锁内创建独立备份。原备份、配置和失败恢复限制保留；成功回执继续以三插件实际版本和配置保全为条件。未删除文件、用户数据或业务能力，已有待重启、活动写者和失败恢复回归继续通过。

修复前新增回归稳定触发同一错误；修复后现有桌面升级集合 123 项、格式与 lint 通过。真实 pnpm 重放升级、恢复旧版和再次升级通过。独立 Mac 临时签名 `.app` 覆盖安装和连续三次退出重开显示登录页，配置、会话测试数据与旧备份保留。后续正式签名双端发行、Windows 托管与实机独立目录覆盖安装和三次原生窗口启动均已通过，完整发行身份与边界见[交付记录](../../../changes/2026/11/12/desktop-upgrade-recovery.md)。
