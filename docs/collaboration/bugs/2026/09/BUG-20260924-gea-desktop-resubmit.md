# 桌面端退回计划无法重提

- 现象：同一账号在 Web 可重提退回计划，桌面端却因服务账号未就绪而无法提交。
- 根因：旧桌面启动链未从钥匙串加载插件所需的服务账号凭据；仅有管理端审批接口并不能补齐桌面 Host 的凭据。
- 修复：将凭据加载放入 Web、桌面共用的插件部署入口；配置仍只保存不含密钥的引用，密钥只从本机钥匙串读取，失败时不留下部分凭据。
- 证据：[插件 MR !179](http://100.100.6.191:20656/chenyonghao/dsh-gea-plugin/merge_requests/179)；在 0.0.124 基线整合后，配置、凭据和登录的 13 项定向测试通过，整版 580 项测试中 577 通过、3 跳过、0 失败。
- 边界：未执行真实生产计划重提；本机用户配置仍须有经批准的 `serviceAccounts.production` 非密钥引用。插件修复不要求重打桌面安装包。
