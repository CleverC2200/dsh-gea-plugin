# 模型总时限与诊断

- 同事截图显示流式读取达到120秒上限；该预算覆盖整次请求，不能据此证明同事网络有问题或连续120秒无输出。
- 候选0.0.130修正模型总时限提示，保留 `GEA_NETWORK_TIMEOUT` 和部署超时语义；不自动重试、不延长默认120秒。
- 增加 GEA_MODEL_FAILURE：关联 requestId/sessionId/model，记录阶段、总耗时、收到响应的耗时、正文字符数和配置预算。无正文、凭据或响应头落入新增诊断。
- `tests/gea-model.test.mjs` 用真实Harness与本地HTTPS模型夹具确认已经输出的流在预算到期后正确失败、取消上游、记录诊断；用户取消和身份变更回归保留。
- 原始事件的模型生成、网关和网络耗时占比仍未知，需要同事会话日志；本卡保持待定位，不将提示修复当成根因已解决。

2026-09-27：提示与诊断改进已随GEA 0.0.130、MR !190发布；原始超时根因保持待定位。
