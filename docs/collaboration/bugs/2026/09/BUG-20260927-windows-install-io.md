# Windows 安装耗时

用户反馈常见约10分钟、个别30分钟。旧阶段报告重复复制475.640秒；候选同盘切换移除第二次整包复制，核心ASAR降低小文件数。0.0.23 Win11初始化至安装完成79.969秒，解压33.922秒、目录切换0.046秒，四项原生探针通过。

- 新插件0.0.130重建后的真实启动和其他机器尚需验证。
- 用户先要求按推荐方案全量实施，后明确要求最新插件重打安装包并上传OSS供用户更新。
