# 新会话 Agent 列表有重复和演示入口

- 现象：默认 Agent 名称、排序与左侧业务目录不一致，列表还有全链库存旧别名和开发中演示入口。
- 修复：默认项改名为“智能编排”，按业务目录排序，开发中演示页仍保留页面但不进入新会话预设；移除全链库存旧别名预设。
- 兼容风险：旧会话若保存并继续按 `gea-html-inventory-all` 解析预设，移除后可能无法打开。用户在查看候选风险后明确回复“移除，然后发版”；候选补丁 SHA-256 为 `cc1335b0284730c6887c762a919d365f02e3760339fcc5f07b44b1bed504f3aa`。这项风险由用户接受，不写成兼容性已验证。
- 证据：[插件 MR !178](http://100.100.6.191:20656/chenyonghao/dsh-gea-plugin/merge_requests/178)；候选整合后 Agent 列表 14 项定向测试通过，整版 580 项测试中 577 通过、3 跳过、0 失败。
