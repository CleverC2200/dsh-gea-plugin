# 销售结果跨来源月份格式

同一业务月在Hive计划结果中使用YYYY-MM，在发货及目标模型中使用YYYYMM。真实问答曾将前一种格式用于后两种来源，即使目录已返回正确样例仍出现空结果。

MR !200集中维护已核实成员的格式与最小查询规则，错误编码出站前给出准确修改提示；未知字段不套此规则，不扩大授权。回归覆盖三源月份、嵌套筛选及无关字符串；同模型/同本机身份真实对照证明正确格式可取到结果。

引入提交未定位。候选版本0.0.134；同事账号及上游同步完整性仍待验收。未修改业务数据、Cube模型或权限。
