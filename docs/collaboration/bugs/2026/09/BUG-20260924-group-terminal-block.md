# 混合终态的审批分组可选但动作被整体锁住

- 复现：同一组织分组同时含待审批计划和状态 5/10 的终态计划。选择框按“存在可操作成员”放行，但按钮随后对全部成员判定，终态成员没有操作授权，导致整组无法通过/退回。
- 修复：仅将 5/10 终态从按钮的待处理成员检查中排除；批次成员仍完整保留，沿用已有 skipReason 返回跳过项。非终态的权限、版本和读取失败继续阻止动作；全终态组仍不可操作。
- `tests/approval-batch-selection-web.test.mjs` 实际浏览器回归通过：混合组可操作、全终态组禁用、取消分组、服务端拒绝后的动作禁用。相关批次与退回重提场景纳入整版回归。
- 没有向真实 GEA 发送审批操作；上述写入场景使用测试网关。
