# HTML 业务插件页适配清单（给各插件仓库）

- 日期：2026-09-22
- 背景：外壳已按窗口宽度分档（≥1680 / 1201–1679 / ≤1200），保证业务页主区宽度**不低于 660px**，并在 ≤1200 时把对话区移到下方。但页面内部布局由各 HTML 业务插件自己负责。
- 适用范围：随客户端安装的 `inventory-*` 页面（产销协同工作台、基地库存、分仓库存、经销商库存、库存管理工作台等）。

## 需要各插件自查的点

| # | 检查项 | 合格标准 |
| --- | --- | --- |
| 1 | 660px 宽度 | 主区 660px 时表格不横向滚动，关键列不折成多行 |
| 2 | 900px 宽度 | 工具栏/筛选行不换行挤压、按钮不被裁 |
| 3 | 1600px 以上 | 内容有最大宽度或按内容分配列宽，不被拉成超宽表格 |
| 4 | 高度 640px | 首屏能看到主要数据区，不只剩筛选条 |
| 5 | 侧栏收起（56px 图标列） | 页面自身布局不因宿主变窄而错位 |
| 6 | 对话区在下方（≤1200） | 页面按「可用高度减半」布局，内部滚动正常 |
| 7 | 长文本 | 组织/客户名等长文本换行或省略都可，但不能溢出单元格 |

## 建议的验收方式

1. 在本地 GEA 工作台打开该页，按 1024×768、1280×768、1440×900、1920×1080、2560×1440 五档截图。
2. 同一张截图里确认：无横向滚动、无文字重叠、无被裁按钮、首屏有数据。
3. 把五张截图附在该插件仓库的 MR 里，作为「分辨率适配」验收证据。

## 外壳侧已经保证的事

- 主区宽度分档：1024→844、1280→700、1366→771、1440→826、1536→897、1600→960、1680→997、1920→1179、2560→1760（1600 上限后内容居中）。
- 对话区在 ≤1200 时移到主区下方，最小高度 220px，不会消失。
- 工作台 iframe 自身可滚动，插件页只需保证内部布局在该宽度下合理。
