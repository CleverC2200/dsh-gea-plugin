# 原正式发行流程追溯

本隔离项目的三核心本地交付使用 [三包打包与接收](package-delivery.md)，安装使用 [当前安装协议](install.md)。目标仓库和写入权限由项目根当前导航、登记仓库与有效授权确定。

[原正式发行流程](history/current-docs-before-20261010/docs/plugin-release-update-guide.md) 按原字节保留，包含旧 GitLab、OSS、频道、源码提交、不可变包与验收门槛。它仅用于追溯历史发行，不授权本项目向正式 GitLab、OSS、npm、频道或正式客户端写入。历史 Runner 状态和个人过程不能当作当前环境事实。
