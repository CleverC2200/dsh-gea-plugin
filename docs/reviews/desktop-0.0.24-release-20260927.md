## 已授权的回收与行为变化

- 只回收正常启动后无状态引用、收据有效的自动插件图；保留当前/上一可用/待重启/手动/固定/迁移引用及未知 staging，不动登录、会话、工作区或全局缓存。该范围在推荐方案中列明并获“全量执行”授权。
- 安装时同路径以目录替换代替旧卸载器，新目录提升失败恢复旧目录；安装成功才回收本次旧安装目录。0.0.23 在 Windows 11 四项真实隔离探针及安装退出通过；安装完成不等于业务启动全部验收。
