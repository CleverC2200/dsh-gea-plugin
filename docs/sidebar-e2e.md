# 侧栏导航验收

顶部品牌区只是标识：思念圆标 + 「GEA平台」+ 一行说明，点它不会换页，也不会触发 DSH 原生的「新建会话」；左下用户头像使用 DSH 原生设置触发器。

左栏是「业务工作台 / 历史会话」两个互斥抽屉，标题都没有行首图标，**展开的内容一律往下长**。顺序是：业务工作台 → 业务导航 → 历史会话 → 会话列表；展开的那个面板会占满剩余高度，因此业务导航展开时「历史会话」会被顶到最下面（用户信息上方），反过来「历史会话」展开时它的会话列表就在该行下面往下铺。同一时刻只开一个（点开着的那个可以收起）。两个面板铺在同一块底色上，和原生侧栏一致，中间不留接缝。

「历史会话」那一行是「标题 + DSH 原生的搜索 / 排序 / 新建工作区按钮」合成的一行；原生那一行在 DSH 的 React 树里搬不动，这里用定位把它落到标题右边（点搜索会在这一行里展开输入框）。历史会话、设置弹窗与会话列表仍由 DSH 原有插槽提供，GEA 只替换品牌、设置触发器内容，以及业务导航的摆放方式。

## 每个工作台对应的会话助手

右侧会话区的名称、常用功能、推荐提问按页配（`src/client/conversation-prompts.ts`），改页面时一起改这段文案：

| 页面 | 助手 | 对齐的工作台内容 |
| --- | --- | --- |
| AI 工作台（首页） | AI 工作台助手 | 入口级：计划建议、重点商品、库存供应风险、提报审批进度 |
| 销售计划 | 销售计划审批助手 | 审批口径：审单、异常清理、双版本差异、审批意见 |
| 区域计划工作台 | 区域计划助手 | 提报与跟催、品类达成、复盘与达成、分析与异常 |
| 经销商库存 | 经销商补货助手 | 客户库存、品类库存、补货建议、重点客户 |
| 需求运营管理 | 需求运营助手 | 需求波动、品类偏差、需求共识待办、活动纳入率 |
| 交付运营管理 | 交付运营助手 | 交付风险、重点订单、履约链路、订单满足率 |
| 安全库存 | 安全库存助手 | 库存水位差额、超龄与货龄、基地/品类结构、订单满足率 |
| 分仓库存 | 分仓库存助手 | 缺货订单、补货确认、大日期与滞库、分仓满足率 |
| 库存管理工作台 | 库存管理助手 | 今日运营概况、今日优先处理事项、缺货与低库存、责任角色与反馈 |
| 全链路库存 | 全链路库存助手 | 全链库存概览、各节点库存、缺货与大日期风险、跨仓调拨机会 |
| 业务待办（顶部铃铛） | 业务待办助手 | 未读待办、卡在本节点的审批、待办分布、处理优先级 |

助手名称下只保留「需求预测 Agent / 库存 Agent / GEA Agent」这行副标，不再挂「审批辅助 / 补货辅助」这类标签。

每个业务页（含 HTML 插件页）和业务待办页都登记了独立会话并在运行时 `showConversation`，右栏统一走停靠布局（欢迎区在流内、输入框贴底），这样既保证每页都有对话框，也不会让欢迎区盖住输入框。会话回复在业务页右侧会话栏可见（只有首屏欢迎区整段隐藏，会话开始后不能再隐藏消息列表）。

品牌行右侧保留业务待办铃铛（进 GEA 消息待办页）和 DSH 原生「收起侧边栏」按钮；侧栏收起后两个抽屉隐藏，只留圆标、AI工作台、搜索和用户入口。

Chrome 实机验证（2026-09-12，127.0.0.1:3201）：两种页面均成功打开设置 dialog，显示通用设置、模型和插件；关闭后 dialog 数量为 0；顶部往返切换后工作台 iframe 数量依次为 0、1。头像 computed style 验证为 50% 圆角；品牌背景为 rgb(237, 0, 0)，用户头像为 rgb(243, 152, 48)。没有执行审批写入或模型推理。

可重复用例位于 `tests/e2e/sidebar.spec.ts`。启动本地 GEA profile 后使用 `npx playwright test tests/e2e/sidebar.spec.ts --browser=chromium`。本轮执行的是 Chrome 连接器中的等价交互和断言，未执行该独立 Playwright runner。

自动回归：`npm test` 中的 `tests/web.test.mjs` 使用隔离的 DSH profile 和 Chrome，先通过首次启动声明，再验证登录布局、品牌样式、两端头像设置、双向切换、窄屏布局，以及已删除工具栏不再出现。外部 GEA 服务由测试夹具替代；该用例还验证按版本匹配的待办启用审批按钮、打开确认弹窗、切换其他节点仍可浏览且禁止错误审批，整个用例不发送审批写请求。`tests/notifications.test.mjs` 同样通过首次声明后验证分页、筛选、详情与权限失败。快照预览和持久化传递继续由 `tests/workbench-host.test.mjs`、`tests/verify-workbench.test.mjs` 覆盖。
