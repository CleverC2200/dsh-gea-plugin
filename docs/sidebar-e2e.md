# 侧栏与页面验证入口

侧栏、品牌、欢迎区、工具栏及 Native/HTML 呈现归同组 Workbench，当前接口见 [Workbench 页面合同](../../dsh-agent-workbench/docs/workbench-contracts.md)。GEA 只提供 [只读身份与账户动作](../src/client.tsx)。用户路径验证按项目根的 `plugin-split-verification` 技能选择既有 harness，并以本票冻结候选、运行窗口和有效授权为准。

[原侧栏验收记录](history/current-docs-before-20261010/docs/sidebar-e2e.md) 按原字节保留，包含旧 DOM/CSS 操作、当时版本与本机页面观察。旧源码路径、端口和通过结论不是当前运行入口；原未执行范围仍保留。
