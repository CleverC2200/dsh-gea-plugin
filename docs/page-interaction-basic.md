# 页面交互基础版

用户批准范围：用 React Grab primitives 点选看板元素或表格行，加入 DSH 原生输入框引用，随问题提供局部内容；有已有元素 ID 时，继续复用页面操作。覆盖原生审批表格及一个隔离 HTML 看板，并抽成独立插件。优先基本可用，不增加管理界面或新业务管控。

工作树：0ba2；分支：codex/page-interaction-basic；开始提交：a6ad4f24162f6f6b475266837f565002a26793ac。

## 交互

1. 点击输入框底部工具栏的指针图标。
2. 鼠标滑动自动高亮所属行、表格或内容块；不再显示层级选择器和预览框。
3. 左键点击高亮范围，直接加入输入框引用标签；退格可删除。
4. 写问题后发送。消息与输入框显示相同引用名称，蓝色下划线，不显示编号；模型按需读取快照。
5. 后续明确要求展开/筛选/填写时，通过现有页面工具执行。

## 实现范围

- `packages/page-interaction`：选择器、DSH 输入框接线、引用格式、通用页面操作桥及本地打包入口。
- GEA Adapter：两种 iframe 接线、原生表格行 ID、筛选范围、HTML 注入和扫描元素标记。
- `src/page-bridge`、draft/layers、payload-budget 保留兼容出口，已有业务规则保持原实现。
- React Grab 0.2.0 仅使用 primitives 命中，不启用源码查找、整页冻结或公网脚本。
- 原生页面和 HTML iframe 都在自己的 document 内点选，沿用现有消息桥与 CSP。

## 工作台通用接入与图标统一

选择入口复用右侧视图按钮组的浅灰底、32px容器、26px按钮和16px图标。区域计划、品类计划和MPS原型统一使用PrototypeWorkbench，在会话就绪后自动绑定离线选择器；原型引用名称标记“原型”。HTML工作台沿用统一Host注入与Frame接线，原生审批接线保留。

新增跨工作台浏览器测试覆盖3个真实原型页面和4个HTML注册路径（产销协同、全链库存、基地库存、分仓库存），逐页引用并检查仅有一个入口；既有原生审批及HTML测试通过。未启用的占位菜单没有新增业务页面。编译期选择脚本内嵌进client，逆序指定build targets也确保先生成选择脚本；空目录包安装验证通过。

## 输入框工具栏与 Alt 快捷键

入口统一由插件注册到原生 conversation.input.left，顶部工具栏不再重复挂入口。按住Alt临时选择、松开退出；点击按钮持续开启直到Esc或再次点击。Alt+左键引用后立即松开，已点击的引用仍会加入输入框。跨父页面/iframe的按键和焦点变化均有回归；浏览器业务工具发起的程序点击不受选择模式干扰。

本轮类型检查及3项浏览器集成测试通过（原生审批、隔离HTML、全部嵌入式工作台），包含跨焦点Esc抑制、松开Alt保留已点击引用、Esc取消等待中的引用。Chrome 3440实页已刷新，底部入口1个、顶部入口0个。
