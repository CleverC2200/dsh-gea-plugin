# 技能版本号相同不代表内容相同

- 状态：已有文件级核验入口；后续仍须在每次同步/发布前执行。
- 分类：本机安装副本与团队来源不同。
- 证据：2026-09-24 比对发布技能，团队来源 `dsh-plugin-releases` 的 `2dc96f7f412fd12f0952d4eba0ed309f36512c13` 与本机均标 `0.7.0`，但 SKILL.md 不同，本机多了 `references/local-packaging-machine.md`。差异是本机打包说明的引用，不据此断言团队版本落后。
- 风险：只比较 version 会漏报；整目录覆盖会丢掉本机专用配置，反向上传本机目录又可能泄露机器信息。
- 防复发：刷新声明的 GitLab 来源，以固定 SHA 获取全部受管理文件并比较 SHA-256；本机专用说明留在 `references/local-*.md`，安装前备份。缺失、未管理差异、本地修改和网络失败分别处理，未知不报最新。
- 验证：同步工具的临时 Git 仓库测试覆盖同版本内容变化、脚本变化、本机修改拒绝覆盖及本机说明保留；每次真实核验输出实际 sourceSha。
