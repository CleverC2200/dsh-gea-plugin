两个方案的差异清单

对比项方案 A · 提报版「销售计划助手」方案 B · 审批版「销售计划审批助手」
使用人客户，以及实际代行提报的 KA／行销综合／业务员审批节点审核人：城市经理（区域计划审批）、省区总、大区总、品类计划
Agent 名称销售计划助手销售计划审批助手
简介口径帮你核对计划合理性、解释依据、按你的意见改草稿；最终提交你自己完成按当前节点核对这张计划、逐条给异常处理建议；只分析，不改审批状态
固定功能区看本月计划建议 · 看需要重点关注的商品 · 解释预测依据 · 按工作台当前结果提交审这张单 · 看异常清理清单 · 看双版本差异 · 生成审批意见
推荐问法这次预测能按现状走吗 / 哪些商品需要重点复核 / 为什么上调了 / 按建议把数量调下来这张单能直接同意吗 / 哪些客户需要退回重提 / 为什么比上一版降了 / 整体达成偏乐观吗
首屏行为打开工作台自动播报本月建议（任务头、总量、关键变化、风险、建议时间）不自动播报；由审核人点「审这张单」或直接提问后给出结论
能做什么可改草稿数量与金额、可展示确认摘要，不代替最终提报全程只读；可给同意／建议修正／退回重提的建议，但不写审批状态
结论形态能否按现状走 + 逐商品方向与幅度结论先行：能不能直接同意 + 卡在哪几项 + 每项给处理动作
风险话术基准达成率 0.9–1.15 健康；货龄 60／90 天分档；库存覆盖对品类周转基准达成率 0.9–1.15 合理；异常按项数分档；纠偏差额超 ±20% 建议走新计划
每轮收尾固定 2–3 个下一步，其中一项是把用户带到确认入口固定 2–3 个下一步，其中一项是走审批工作台执行
数据范围当前页面这位客户（列表页只对列表内客户生效）当前节点待审范围；大区／省区按整体校验，不拆单销售组

两版共用同一套头像资产、同一套消息流与输入区交互，差别只在名称、简介、固定功能区、推荐问法与权限边界。因此前端可做成同一个会话组件，用配置项切换两套文案与可用动作。

数字颜色在两版中语义一致：超计划为红、低于计划为绿；品牌红仅用于主按钮与少量强调，不与差额语义混用。头像取用交付包的圆角方形主版（首页 72px）与圆形版（头部 30px、每条回复 26px），页面内已按 2 倍取图内嵌。
