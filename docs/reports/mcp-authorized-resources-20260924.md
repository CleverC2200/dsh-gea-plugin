# MCP 授权资源接口接入与查询执行验收

2026-09-24；工作区 `/Users/synear/.codex/worktrees/adfd/dsh-gea-plugin`，分支 `codex/preview-web-20260923`。沿用已有未提交修改；本次仅更新 3199 开发实例，没有发布插件或客户端版本。

## 已实施

- `gateway-mcp.ts` 在可信 Gateway Session 内封装 `POST /ai/gateway/mcp/proxy/resources`。MCP 编码从 `tools/list` 返回的真实路由取得；模型不能填写 Session、委托令牌或租户。令牌仅放请求体，资源发现日志脱敏且禁止重放。
- 每次目录读取和业务请求都重新获取授权资源快照，失败关闭。HTTP 200 的业务失败、审计失败、会话失效、不可用接口及格式异常都不会降级为公开 inspect；429 保留 Retry-After。成功空列表明确为无匹配授权资源，不解释成业务数据为空。
- Cube 目录只展示 `EXTERNAL_MCP.queryTarget` 与 inspect 的交集。删除进程级“模型最后被哪个 Agent inspect 就归哪个 Agent”的缓存。不同 Agent 的授权互不覆盖；其它资源类型不当作 Cube 模型或数据库表名。
- 成员目录按 MCP 模块会话缓存；身份切换使用新模块，资源版本变化使旧成员目录失效。授权资源列表不从目录缓存回放。
- 新增 `gea_cube_query`，向模型提供具名查询、维度、度量、筛选、排序、时间维度和分页的嵌套参数定义。Agent 编码来自当前注册表。旧 `gea_module_mcp` 复用同一执行逻辑；其 inspect 也过滤授权资源。
- 同批独立查询按模型拆开，同一 Agent 执行；单条跨模型、未授权目标、非唯一资源映射、错误成员和超行数限制被拦截。默认 limit=50，受业务上限200及资源maxRows共同约束；空限制值不代表无限制，实际字节数和行范围仍由网关判定。
- 分组执行保持原查询参数，分别报告成功、失败和拒绝项；保留已有成功回执与未完成项。中止后不继续下一组，失败后不自动切换 Agent。
- 数值维度不推荐为汇总度量；相近拼写明确标注“不代表业务含义相同”。Skill 和系统协议明确区分安全库存身份与需求预测身份，Cube 优先走新入口。未知单位/币种要求展示原值并注明待确认。

## 已完成的线上资源配置

在用户授权执行后，已建立并发布 `agents_aps_sales_budget-cube` 与 `agents_dim_cust_detail_df-cube` 两条 EXTERNAL_MCP 资源，分别配置3个组织范围字段、4个组织/客户范围字段。均绑定现有 `query_business_data` 能力，保留范围过滤。

`sales_forecast` 策略增补两条 ALLOW 资源授权，沿用同类资源既有的 `DEPART_AND_CHILDREN / DEFAULT / 200行 / 262144字节` 边界。原19条授权项保留，更新后21条。平台更新产生新授权版本，已按最新版本核验；没有重复提交更新。

新资源发现接口的现场响应返回26条资源，包含上述两项。通过实际宿主注册的工具发起混合模型批次，预算月份返回33行、客户受限样本返回3行，均进入成功回执，未完成清单为空。

## 边界与待业务核对项

资源授权不代表字段、业务行范围和执行条件必然通过。上述真实模型复跑验证了取数链路；其最终回答仍自行换算了“万元”，不能视为已确认币种和单位。系统协议已要求未知单位只展示原值，仍应由业务确认源模型口径后进行业务验收。

新接口还揭示：`agents_scm_demand_accuracy` 与 `agents_scm_sales_accuracy` 两条授权资源指向同一个 `agents_scm_demand_accuracy` queryTarget。客户端对此失败关闭，未猜测或改写线上资源归属。这一模型的绑定需平台单独核对，不影响本次预算与客户查询验收。
