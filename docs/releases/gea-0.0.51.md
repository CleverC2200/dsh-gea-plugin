# GEA 0.0.51

## 变更

- 对接新版用户端消息待办字段，展示完整正文、业务类型、通知时间、销售计划动作和服务端受控目标。
- 增加单条已读、批量已读、忽略和站内审批动作的 Host 代理，统一使用版本校验和幂等键。
- 消息待办页面支持批量选择、标记已读、忽略、同意和驳回，并保留服务端状态为最终权威。

## 边界

- 本版暂不接入通知偏好和 SSE 实时事件流。
- 受控目标只展示服务端返回值，完整 Client Navigation 由后续客户端桥接联调完成。
- 本版不修改 GEA 后端、DMS 或桌面客户端。
- 状态变更使用原始请求语义处理未知结果；冲突和不可执行动作会刷新通知状态。
