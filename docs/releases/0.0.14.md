# GEA 0.0.14

基线：gea-v0.0.13。修复需求预测会话将 Skill 本地参考文件误交给 GEA MCP，以及中文问题出现英文进度说明。

- 增加仅需求预测预设可用的 gea_skill_reference_read，只读加载当前可见 Skill 正文直接链接的本地文件，支持行分页。
- 网关在发送前拦截 file: 资源读取，并引导使用本地读取工具；真实 MCP 资源 URI 和已有路由、身份校验保持原有行为。
- 首轮 Persona 明确跟随用户语言，中文问题的进度与结果均使用中文。

## 验证

- TypeScript、构建和 21 项相关测试通过，包含既有网关路由、发现分页、登录失效及本次资源读取回归。
- 显式文件清单打包检查通过；新增 lib/skill-reference.js 随预设一起分发。
- 从 tarball 解压到独立目录并安装生产依赖，用实际安装后的 DSH profile 运行 8 项工具循环测试通过；包含 Skill 加载、本地规则读取和后续模型请求。
- 模型与业务服务在回归测试中使用受控响应，没有查询真实生产业务数据；未验证模型对中文提示词的统计遵从率。
- 未改变桌面壳、更新器或依赖图，复用既有 Electron 更新/重启链路证据。本次验证平台为 macOS。

## 升级

仅更新 GEA 插件。更新完成后重启客户端，并新建需求预测会话。
