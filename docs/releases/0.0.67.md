# GEA 0.0.67

新增独立的「区域计划工作台」菜单页（内嵌业务原型），并修掉切换业务页时的闪屏。

- 「计划管理」下新增「区域计划工作台」菜单页，内嵌业务侧原型《区域计划工作台 V9 事件线版》（计划事件线、提报与跟催、品类、复盘与达成、分析与异常五个模块）。该页是纯原型，数据全部为模拟数据，不连 GEA、不需要登录。
- 「需求提报」页去掉「销售计划审批 / 区域计划评估」两个页签和对应的空占位页；区域计划评估已作为独立菜单页使用。页面标题改为普通标题显示。
- 修掉切进业务页时闪出「GEA 扫码登录」页的问题：只有子页面明确回报未登录时才铺整屏登录遮罩，首次挂载不再先渲染登录页。
- 修掉点进「需求提报」整屏白闪约 120ms 的问题：已登录时工作台不再被登录遮罩临时拉到整屏，页面直接落在中间列。
- 业务面板之间切换时不再播放框架的 400ms 列宽动画，避免工作台跟着连续重排。
- 审批页头部：标题放大到 20px 加粗并去掉下划线；标题栏与「客户提报…品类计划审批」节点条改为贴边显示，去掉标题栏外边距与圆角。
- 「需求提报」的「月初 / 纠偏」单据类型切换保持不变。

测试补充：新增 `tests/regional-plan-page.test.mjs`（验证新菜单页可打开、审批页不再有「区域计划评估」页签、已登录时工作台 iframe 留在中间列），并在 `tests/logout.test.mjs` 增加「未登录时才铺整屏登录遮罩」的断言。

仅插件发版，未重打桌面客户端。
