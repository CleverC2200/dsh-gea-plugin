# GEA 0.0.16

销售计划审批按 V1.2 口径区分可操作、只读跟踪和不可见。默认显示本人可见范围，节点按钮只筛选待办，不再自动把空待办扩大成所有状态。

## 来源与实现

- 源码基线：公司 main / gea-v0.0.15，3f71ed0a979e5ac6619fdcb726dbb0b2b7712c39。
- 从 GEA `/sys/permission/getPermCode` 的 `codeList` 读取本人权限；不把 `allAuth` 全局配置当授权。二维码登录与桌面恢复均接入，恢复不信任持久化的旧权限。
- 在服务端组织和有效版本范围内，列表、分页、汇总和进度使用同一角色状态过滤。区域 1/7、省区 2/8、大区 3/9 可操作；自己发起的退回只读，其余退回隐藏。多角色取可见范围并集。
- 无节点权限编码的旧服务保留原有服务端可见范围；写入仍需对象能力、精确版本的任务授权或本人节点权限，最终由 GEA 校验。
- 退回 7/8/9 纳入精确版本任务发现；无效版本不查询授权。操作额外校验列表与详情计划类型一致。
- 保留配置驱动的 XN 跳过区域、6 重提到 2，以及既有状态 10 单独授权 SAVE；5/10 不开放审批或退回。
