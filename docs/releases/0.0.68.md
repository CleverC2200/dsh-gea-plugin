# GEA 0.0.68

「需求提报」改名「销售计划」，右侧 AI 会话区按原型说明 V1 重做，区域计划工作台补上完整左中右布局。

- 「计划管理」下的「需求提报」改名「销售计划」。
- 「销售计划」页右侧会话区按《销售计划 · 右侧 AI 会话区原型说明 V1》落地：数字人头像（首页 72px、顶栏 30px 圆形）、名称与能力标签、简介卡（边界句加粗）、固定功能区 4 项（线框图标 + 一行说明）、推荐问题 4 条、脚注「AI 生成内容请判断后使用」。文案为审批版（销售计划审批助手）；提报版（销售计划助手）文案与规则已入库，暂未挂页面。
- 会话栏顶部名称行改为冻结：不随卡片或消息滚动，首页与会话中常驻。
- 「区域计划工作台」改为与其他业务页一致的左中右布局：左侧导航 + 中间原型 + 右侧「区域计划助手」会话区（4 项固定功能、3 条推荐问法），并修掉该页输入框被首页卡片盖住的问题（输入框重新停靠在会话栏底部）。
- Agent 提示词补充会话区规则：提报版/审批版回复骨架（结论→依据→缺口→下一步 / 结论→三维对比→卡点逐条→动作枚举）、每轮固定 2–3 个下一步选项、面向用户不再出现「把握度」而改用「发货概率 + 近六个月进货月份数与断月情况」、审批版只读边界与「无异常，可直接同意」、提报版首屏五段结构与「采纳不等于提交」、阈值口径（达成率 0.9–1.15、货龄 60/90 天、纠偏差额 ±20%）与数字颜色语义（超计划红、低于计划绿）。
- 原型与说明入库 `docs/prototypes/`（销售计划对话区原型说明 V1 + 提报版/审批版原型 HTML）。

本期未做（后续统一处理）：会话中的结构化回复卡片（等统一卡片工具）、提报版首屏自动播报、顶栏动态副标（当前节点/待审张数）、提报端页面。
