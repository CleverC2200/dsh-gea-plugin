# GEA 0.0.25

## 变更

- 修复销售计划审批入口把“当前节点未通知该角色”误判成“该角色无审批权限”的问题。
- 用户持有区域、省区、大区或品类审批权限时，只要该计划对该角色可见且仍处于可处理状态，就能进入审批；对象动作能力继续作为补充证据。
- 真实写入仍由 GEA 接口按组织、角色、版本、状态和快照重新校验，客户端不会绕过服务端审批规则。

## 验证与边界

- 角色访问模型、Host 写入门禁和浏览器交互回归测试通过；覆盖“有区域审批权限、能看到计划、对象能力仅记录当前通知节点”的场景。
- TypeScript 检查、构建、打包和包内容校验通过。
- 本次只修改 DSH/GEA 插件客户端权限投影，不修改 GEA 后端、DMS、依赖、包入口、打包方式或桌面壳。
- 发布到 `dsh-0.1.6-test.json` 与 `dsh-0.1.6-stable.json`；旧频道不推进。
