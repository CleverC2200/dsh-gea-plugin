# GEA 0.0.24

## 变更

- 工作台提交销售计划只读快照时，不再把完整 JSON、SHA-256 和接口地址作为普通用户消息直接铺在对话中。
- 快照改为 DSH 原生 `notice` 上下文：对话默认只显示“已提交只读分析：对比所选计划的数量和金额差异”，原始数据默认收起。
- 模型仍接收完整、可校验的只读快照；分析任务、来源、覆盖范围和“不得审批或写回”约束保持不变。
- 本地数据传递验证使用独立摘要“已提交只读快照，正在验证数据传递”，避免把验证回执误解为业务分析。

## 验证与边界

- TypeScript 检查、构建、真实 Session 落盘、失败重试、模型入参和工作台查询相关测试通过。
- 新增回归断言：模型和本地回执两条路径均使用折叠 `notice` 来源，不再生成普通用户来源的原始快照消息。
- Impeccable 界面规则扫描与 `git diff --check` 通过。
- 完整测试套件 160 项中 155 项通过；5 项既有审批/重提/保存/响应式页面用例失败，不涉及本次会话展示链路。本次发布不修改 GEA 后端、DMS、依赖、包入口、打包方式或桌面壳。
- 复用 0.0.23 已验证的 DSH `0.1.6-alpha.1-company.1`、工作台 `0.1.1` 和桌面 `0.0.10`、`0.0.11-preview.20260915`、`0.0.11` 兼容组合；发布到 `dsh-0.1.6-test.json` 与 `dsh-0.1.6-stable.json`。
