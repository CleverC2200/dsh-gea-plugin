# GEA 0.0.19-beta.2（测试频道）

基于 0.0.18，保留登录恢复、角色权限和 MCP 会话恢复逻辑。

- 审批头部紧凑单行；左侧导航收起后以图标显示。
- 组织就地展开 SKU，按品类分组；只读调整抽屉仅展示有变化 SKU，数值和 AI 建议分区。
- 历史版本比较与组织数量目标汇总；切换节点时保持进度统计范围。
- 调整草稿自动暂存于当前 Host 私有目录，审批前不写正式计划；尚不支持 GEA 草稿落库或跨实例同步。
- 页面自动建议及 SKU 建议提供失败提示与重试。

限制：生产物料描述缺失和真实模型回复与快照不一致仍需联调；右侧 Agent 完整折叠循环未全量验收。本版本不是全部问题已解决的正式版。

验证：类型检查与构建；角色、权限、统计针对性测试；受控 GEA/模型下的浏览器视觉与交互回归。正式业务审批写入不在本轮测试范围。

补充：客户编码缺失时跳过无效筛选项，避免整页白屏。beta.1 仅上传候选包，未进入频道。
