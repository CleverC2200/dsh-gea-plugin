## 二、本轮改动明细（含前后对比与原因）

### A. 外壳分档（`src/client/shell.css`）

- **改动内容**：主区/对话栏/侧栏按窗口宽度分三档 —— ≥1680：侧栏 280 + `clamp(400,24vw,520)`；1201–1679：侧栏 240 + `clamp(340,26vw,400)`；≤1200：主区在上、对话区在下，对话区最低 220。
- **原因**：原来侧栏 280、对话栏固定 440，1280 时只剩 560 给主区，而工作台表格最小要 660、标题行要 ~880 → 表格横向滚动 + 标题重叠。
- **前后对比**（销售计划审批页）：

| 窗口 | 侧栏 | 主区 | 对话栏 | 表格是否横滚 |
| --- | --- | --- | --- | --- |
| 1280 改前 | 280 | 560 | 440 | 是（660 > 560） |
| 1280 改后 | 240 | 700 | 340 | 否 |
| 1536 改前 | 280 | 816 | 440 | 否（但标题行重叠 39×15px） |
| 1536 改后 | 240 | 897 | 399 | 否 |
| 2560 改前 | 280 | 1840 | 440 | 否（列被拉到 672–351px 过宽） |
| 2560 改后 | 280 | 1760 | 520 | 否（对话栏跟着变宽） |

### B. 工作台标题行换行（`RegionalApprovalWorkbench.module.css`）

- **改动内容**：`.header` / `.headerRight` 允许换行（`flex-wrap: wrap` + 行间距）。
- **原因**：窄宽度下右侧「当前节点 + 计划月份 + 版本 + 对比」被压到标题和单据类型页签上，出现文字互相压住。
- **前后对比**（重叠面积检测）：

| 窗口 | 改前重叠 | 改后 |
| --- | --- | --- |
| 1280 | 标题×徽标 53×15、月初×徽标 42×15、纠偏×周期 38×28 | 0（换行成两行） |
| 1366 | 标题×徽标 80×15、纠偏×周期 10×28 | 0 |
| 1440 | 月初×徽标 58×15、纠偏×徽标 31×15 | 0 |
| 1536 | 纠偏×徽标 39×15 | 0 |
| 1600 及以上 | 0 | 0（仍是一行） |

### C. 对话欢迎区可滚动（`src/client/shell.css`）

- **改动内容**：业务页欢迎区在 hero 阶段从顶部排布（`justify-content: flex-start`），超出部分滚动可达。
- **原因**：原生居中排布在窄栏/矮窗口下会把推荐问题压到输入框下面，看起来像「少了内容」。
- **前后对比**：1280×768 改前最后两条推荐问题被输入框盖住；改后从顶部起排、可滚动查看全部。

### D. 对比度修复（`src/client/shell.css`）

| 元素 | 改前 | 改后 | 原因 |
| --- | --- | --- | --- |
| 品牌副标题「智能体工作台」 | `#96999f`，2.73:1 | `#666c76`，5.06:1 | 低于 WCAG AA 4.5:1 |
| 侧栏选中项（浅红底 `#fff0f2`） | `#df1732`，4.41:1 | `#d0132c`，4.98:1 | 同上；悬停态在 `#fffafb` 上是 4.72:1，保持不变 |

### E. 窄宽度下组织名不再省略号截断（`RegionalApprovalWorkbench.module.css`）

- **改动内容**：容器 ≤900px 时，组织名称/组织路径由「单行省略号」改为「换行显示」；宽屏保持单行省略，行高不变。
- **原因**：1280 那种列宽（约 251px）下「浙沪经销业务(不用)」会被截成「浙沪经销业务(不…」，用户看不到完整组织名。
- **验证**：1280 下 `.detailTrigger` 计算样式 `white-space: normal`（换行生效）；宽屏规则未改。
- **限制**：夹具数据没能渲染出超长组织名，实际观感需要真机再确认一次。

## 三、按推荐落地的第二批（2026-09-22）

### F. 超宽屏内容上限（`RegionalApprovalWorkbench.module.css`）

- **改动内容**：工作台页内容（标题行 / 流程图区 / 主体区）统一 `max-width: 1600px` 并居中；1600px 以下窗口不受影响。
- **原因**：2560 下表格被拉到 1758px、四列 672/328/328/351，扫视距离过大（DESIGN.md 也要求桌面端给内容设上限）。
- **前后对比**：2560 表格宽度 1758 → **1598**；1920/1440/1280 不变（1177 / 824 / 698）。

### G. 矮窗口欢迎区压缩（`src/client/shell.css`）

- **改动内容**：窗口高度 ≤940px 时，欢迎区隐藏「常用功能」的一行说明、常用功能只留前两条、收紧间距；≤780px 时再收掉头像。
- **原因**：1280×720/768、1440×900 这类常见高度下，推荐问题会被挤到折叠区外，需要滚动才能看全（看起来像少了内容）。
- **前后对比**（欢迎区自身滚动溢出 / 最后一条推荐问题是否可见）：

| 窗口 | 改前 | 改后 |
| --- | --- | --- |
| 1280×720 | 溢出 35px，最后一条不可见 | 溢出 0，4 条全可见（常用功能 2 条 + 收掉头像） |
| 1280×768 | 溢出 35px | 溢出 0 |
| 1440×900 | 溢出 18px | 溢出 0 |
| 1920×1080 | 0 | 0（保持 4 条常用功能 + 说明） |

### H. 桌面最小窗口（`desktop/main.cjs`）

- **改动内容**：`minWidth` 760 → **1024**，`minHeight` 600 → **640**。
- **原因**：原最小值下侧栏只剩图标列、主区 400px、表格必须横向滚动，界面不可用。
- **为什么不是 1280**：1366×768 笔记本在 Windows 125% 缩放下可用宽度只有 1093px，设 1280 会让窗口大过屏幕。1024 是能保证「两行布局 + 主区 844px」的可用下限。
- **生效范围**：这是桌面壳参数，需要下一次桌面安装包才生效；插件版本不影响。

### I. 插件页适配清单

HTML 业务插件页（库存/经销商等）的源码在各自仓库，外壳只保证给到 ≥660px 宽度。清单见 [html-plugin-adaptation-checklist.md](html-plugin-adaptation-checklist.md)。

### J. 设计系统漂移（建议单独排期）

- **现状**：检测器在工作台里报出 280+ 条「字号/圆角/颜色不在 DESIGN.md 台阶上」的提醒（如 9/10/11/13/16/17/20px、圆角 7/12px、硬编码 #165dff / #111 / #242424 等）。
- **影响**：长期一致性风险，不影响本次分辨率适配。
- **建议**：单独排一个「统一字号/圆角/颜色 token」任务，先定 DESIGN.md 台阶再批量替换；不要在适配任务里顺手改。
