数量只有dimension而没有sum measure、单位与完整快照缺失、销售没有确定性省区聚合等，属于数据/接口能力问题；仅开权限无法解决。上轮Cube候选仍保留为本地待审文件，本轮没有宣称这些线上能力已补齐。
