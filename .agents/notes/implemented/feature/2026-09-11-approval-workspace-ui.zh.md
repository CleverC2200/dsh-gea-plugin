# Agent Note: GEA 审批工作台保持只读

Status: implemented

## 背景

参考页面使用三列审批工作台，包含组织导航、计划队列和分析面板。当前插件已确认的 GEA 接口提供计划只读数据，但还没有稳定的用户范围审批节点写入协议。

## 决策

插件增加工作台框架和组织维度选择，同时保持审批相关操作只读。摘要值来自当前页面数据，未从上游返回的字段继续显示未知，分析操作只把选中的计划快照交给现有 dsh Session。表格保留计划/版本标识、组织、类型/状态、数量、金额和更新时间。

## 放弃的方案

插件不伪造节点进度、审批权限、保存、通过、退回或消息待办状态。这些能力需要确认 GEA 协议和用户权限；也不修改 dsh 核心、不引入 AionUi 运行时依赖。

## 验证

Web 回归覆盖审批标题、组织选择、只读提示、预览前禁用传递按钮和持久化 Session 回执。类型检查、构建和完整无密钥测试通过。

## 限制

当前提交是页面迁移步骤。节点状态、写操作、消息待办和生产验收仍由插件 Issue 跟踪。
