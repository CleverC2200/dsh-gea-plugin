# 产销指标业务定义

来源：业务提供《产销协同主Agent与技能_V2》，接入日期2026-09-27。原文业务确认声明不代表技术执行验证；按本题指标读取。

共用名词：

- SKU：单品识别单位，具体规格及换算采用企业主数据。
- OMS／O：附件中的订单管理系统及其业务简称；T、W分别指附件的后续系统，具体名称与职责待企业知识确认，不猜扩写。
- 初版／纠偏：不同形成时间的计划版本，分析须注明主体和适用窗口。
- 已开／未开订单：不同开单及下发阶段，按系统状态定义识别，不能直接合并缺口。
- 可用库存：满足业务使用条件且可分配的库存，不自动等于账面库存。
- 大日期：附件以生产日期距库存快照日期超过60天识别的库存；具体龄段边界待确认，不自动等于食品保质期定义。
- T+1：按业务日次日更新；实际覆盖截止以取得的数据为准。
- 供需匹配：将具体需求连接到库存或生产、采购、调拨供给，包含数量和可用时间。
- 百分点：两个百分率的直接差，与相对变化百分比区分。
- 证据状态：已验证、有支持但待验证、业务假设、数据缺失、口径冲突。

关键业务公式：

```
订单满足率 = Σ发货数量 / ΣOMS原始需求量
准交率 = 准交订单张数 / 当期应交付订单张数
生产计划达成率 = Σ实际产出量 / Σ同期计划产出量
大日期数量 = 同一库存快照内，库龄超过60天的库存数量之和
产品新鲜度 = 1 - 大日期数量 / 同快照总库存量
可发货天数 = 当前可用库存 / 日均需求
日均需求 = (月度需求计划 + 月度调拨出库计划×0.5) / 当月天数
需求预测达成率 = 月度累计发货量 / 整月需求预测量
销售提报达成率 = 月度累计发货量 / 整月销售提报量
销售预算达成率 = 同期不含税销售额 / 同期销售预算
任务完成率 = 按要求完成的任务数 / 同期应完成任务数

单品偏差量 = IF(下单量 > 计划量,
                  发货量 - 计划量,
                  MAX(下单量, 发货量) - 计划量)
单版本准确率 = 1 - ΣABS(单品偏差量) / Σ单品计划量
最终月度准确率 = 初版准确率×50% + 月中纠偏准确率×50%
```

上述准确率公式用于需求预测准确率；销售提报准确率按附件相同形式分别计算，计划主体、版本和数据不能混用。比率按百分比展示。作废率、改单率、超时及预警指标的特定对象、锁定窗口、时效与去重规则按补充知识执行，未明确的部分列为待确认。

企业阈值与数字化映射保留在指标知识范围内，后续补充时以对应适用版本核对，不能反向改变已确认业务公式。


## 执行边界补充

- 准确率先在已确认的客户/基地/SKU/计划月/版本业务键计算偏差和ABS，再向上汇总，不能先合并不同客户或基地后抵消。核对初版与纠偏对应的实际截止和覆盖；缺任一版本不算最终50%加权值。
- 订单满足的发货/原始需求与页面1−缺货/需求，只有同订单池、截止、单位且缺货=需求−发货时等价；截零、取消、替代品及未开订单可能改变定义。
- 准交先核实是否一行一个最终整单结果；多行订单不能因任一行准交就计整单准交。按企业整单规则归并，分母包含应交未交订单。
- 新鲜度必须检查库龄、数量及库存范围缺失。age_days为NULL不能算非大日期ELSE 0；未知库龄数量单列，不输出完整新鲜度。只算已知子集时明确覆盖，不推断全量。
- 大日期60天、调拨系数0.5、年度月均仅用于本指标业务版本和适用范围。年度月均与跨组织分子分母加权分别处理；缺月、零预算和未结月不自行补齐。
- 本任务确认单位为件的列仅包括Hive计划plannum/allnum和库存qtylive，不推广到inv_qty、其它预测历史量或金额币种。经销商既有库存箱口径独立保留。
