# GEA日志采集（Windows）

适用于已具备 .NET Framework 4.8 的 Windows 10/11。普通用户双击 `GEA日志采集.exe`，无需安装工具或选择日志目录，即可生成桌面 ZIP。工具使用系统运行时，采集、脱敏及 ZIP 打包在本机执行，不自动上传，不提权，不修改应用或系统设置。

| 范围                   | 数据与限制                                                                                                                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 启动                   | 当前 GEA 主进程及子进程的启动时间、角色、版本、父子关系，以及已持久化的技术日志和 Host 数值退出码。自动识别已知目录、当前环境的数据目录覆盖及客户端 `--user-data-dir`。没有近期日志时补读有限数量的最近历史日志，保留文件时间。旧客户端没有写入的历史输出不会补造，缺失仍明确标记 |
| 更新                   | JSON、JSONL、多行 JSON 回执、pnpm 进度和错误码、包名版本、前后台版本证明及安装阶段。当前客户端准备记录、更新指针及其引用的操作回执按持久状态读取，不受 24 小时日志窗口限制；备份、归档和纯握手文件不占诊断文件配额；无诊断字段的有效资料明确排除，真正的截断记录仍标为不完整      |
| 网络                   | 对两个固定服务执行 DNS 和无凭据 HTTPS HEAD 检查。先使用系统 TLS 协商，失败后用 TLS 1.2 对照，保留每次结果和错误分类。始终使用系统证书校验，不改注册表、代理或信任根，不尝试 SSL 3.0 或 TLS 1.0                                                                                    |
| 环境、接口、事件、资源 | 系统与软件版本、磁盘和内存、安全软件登记、接口关联编号和状态、相关 Windows 事件及四次进程资源采样                                                                                                                                                                                 |

六组采集分别在工具自身的独立子进程中执行，输出 UTF-8 技术文件。每组最多运行 25 秒；超时或单组失败写入缺失报告，其余组继续收集。取消时停止并等待本次拥有的进程树退出，关闭窗口也等待清理完成。ZIP 直接包含“诊断数据”目录、收集清单及阅读说明，不再嵌套归档。只导出允许的技术字段；凭据文件、登录令牌、请求头、请求正文、响应正文、完整命令行和业务会话不进入报告。用户名路径遮盖，技术关联编号及安装路径保留。单来源最多读取末尾一 MiB，每组输出最多三 MiB；文件数、目录数量、深度及真实读取失败均在清单中列明。

Windows 构建使用 `build.ps1 -OutputDirectory <产物目录>`，仅交付一个 EXE。脚本使用系统 .NET Framework 编译器并声明 4.8 运行目标，系统 TLS 默认值保持现代兼容行为。开发构建尚未公开可信签名，不代表真实互联网下载后的 SmartScreen 或其他设备安全软件验收通过。Mac 产品化保持待推进。

合成验收使用 `GEA日志采集.exe --acceptance <当前用户TEMP下的新目录> --headless`；去掉 `--headless` 可查看真实窗体。`tests/run.ps1 -BuildDirectory <构建目录> -OutputDirectory <新测试目录>` 检查格式解析、脱敏、自定义数据目录、历史日志、文件筛选配额、采集超时、进程树取消、部分报告及打包取消。Windows CI 另用普通权限令牌从无参数默认入口打开单文件，检查可读 ZIP、复制摘要、资源管理器打开目录并定位文件，以及取消和关闭窗口时等待清理。普通令牌下的 `tests/verify.ps1 -Executable <EXE> -OutputDirectory <新测试目录>` 检查真实系统接口、缺失提示和取消。合成资料不能替代原故障电脑的重跑验收。
