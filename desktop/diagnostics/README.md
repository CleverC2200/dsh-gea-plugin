# GEA日志采集（Windows）

普通用户双击 `GEA日志采集.exe`，无需安装额外运行时或选择日志目录，即可生成桌面 ZIP。工具内置固定版本 Troubleshoot，收集、脱敏及打包在本机执行，不自动上传，不提权，不修改应用或系统设置。

| 范围                   | 数据与限制                                                                                                                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 启动                   | 当前 GEA 主进程及子进程的启动时间、角色、版本、父子关系，以及已持久化的技术日志和 Host 数值退出码。自动识别已知目录、当前环境的数据目录覆盖及客户端 `--user-data-dir`。没有近期日志时补读有限数量的最近历史日志，保留文件时间。旧客户端没有写入的历史输出不会补造，缺失仍明确标记 |
| 更新                   | JSON、JSONL、多行 JSON 回执、pnpm 进度和错误码、包名版本、前后台版本证明及安装阶段。当前客户端准备记录、更新指针及其引用的操作回执按持久状态读取，不受 24 小时日志窗口限制；备份、归档和纯握手文件不占诊断文件配额；无诊断字段的有效资料明确排除，真正的截断记录仍标为不完整      |
| 网络                   | 对两个固定服务执行 DNS 和无凭据 HTTPS HEAD 检查。先使用系统 TLS 协商，失败后用 TLS 1.2 对照，保留每次结果和错误分类。始终使用系统证书校验，不改注册表、代理或信任根，不尝试 SSL 3.0 或 TLS 1.0                                                                                    |
| 环境、接口、事件、资源 | 系统与软件版本、磁盘和内存、安全软件登记、接口关联编号和状态、相关 Windows 事件及四次进程资源采样                                                                                                                                                                                 |

所有收集器通过标准输出传递 UTF-8，中文系统名称及路径保持有效编码。只导出允许的技术字段；凭据文件、登录令牌、请求头、请求正文、响应正文、完整命令行和业务会话不进入报告。用户名路径遮盖，技术关联编号及安装路径保留。单来源最多读取末尾一 MiB，每组输出最多三 MiB；文件数、目录数量、深度及真实读取失败均在清单中列明。

Windows 构建使用 `build.ps1 -EngineDirectory <官方引擎解压目录> -OutputDirectory <产物目录>`。脚本核对 `engine.json` 的固定摘要并内嵌引擎与许可，使用系统 .NET Framework 编译器，并声明 .NET Framework 4.8 运行目标，使系统 TLS 默认值按现代兼容行为生效。开发构建尚未公开可信签名，不代表真实互联网下载后的 SmartScreen 或其他设备安全软件验收通过。Mac 产品化保持待推进。

合成验收使用 `GEA日志采集.exe --acceptance <当前用户TEMP下的新目录> --headless`；去掉 `--headless` 可查看真实窗体。`tests/run.ps1 -BuildDirectory <构建目录> -OutputDirectory <新测试目录>` 检查格式解析、脱敏、自定义数据目录、历史日志与文件筛选配额。普通令牌下的 `tests/verify.ps1 -Executable <EXE> -OutputDirectory <新测试目录>` 检查真实系统接口、缺失提示和取消。合成资料不能替代原故障电脑的重跑验收。
